JewelAura - LAPTOP CAMERA ONLY

This version intentionally DOES NOT use phone/virtual cameras such as:
- OnePlus Nord CE 2 (Windows Virtual Camera)
- DroidCam
- OBS Virtual Camera
- Iriun
- Camo
- ManyCam
- EpocCam

RUN:
1. Open this folder in VS Code.
2. Right-click index.html -> Open with Live Server.
3. Use http://127.0.0.1:5500/...
4. Close Windows Camera/Teams/Zoom/WhatsApp before testing.
5. Click Start Camera.

If the dropdown says "No physical laptop camera found", the laptop webcam is not being exposed to Chrome by Windows. Enable Windows Settings -> Privacy & security -> Camera -> Camera access and "Let desktop apps access your camera". Also check Device Manager -> Cameras.
